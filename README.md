# Tripnest

TripNest — Your complete travel & stay hub. Discover, compare and book over 2,000,000 hotels, luxury villas, beach resorts, and apartments with guaranteed best prices, interactive maps, and Genius loyalty perks.

## 🚀 Key Features

- **Intuitive Search & Discovery**: Dynamic autocomplete across major cities, landmarks, airports, and budget-friendly destinations.
- **Dedicated Flow**: Landing Page Showcase ➔ Dedicated Login ➔ Rohit's Personalized Dashboard.
- **Interactive Map View**: Leaflet OpenStreetMap with custom price markers, interactive popups, and hotel cards.
- **Genius Loyalty System**: Instant 10% discount, complimentary breakfast perks, and zero booking fees.
- **Live Booking & Checkout**: Complete checkout flow with instant voucher generation (`TN-XXXXX`), confirmation emails, and print-ready receipts.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Design tokens, BEM architecture, responsive layouts), Vanilla ES6+ JavaScript.
- **Maps**: Leaflet.js & OpenStreetMap tiles.
- **Bundler & Dev Server**: Vite.

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
